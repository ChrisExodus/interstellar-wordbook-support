技术支持

App 离线可完整使用；iCloud 仅用于可选的学习进度同步。

支持页面版本 1.0 · 2026-08-10

开始学习

  1. 点击单词卡显示释义。
  2. 按掌握程度评分，App 会安排下次复习。
  3. 在统计页查看总进度，在循环播放中复习所选词组。

iCloud 同步排查

  1. 确认“设置 → Apple 账户 → iCloud”已登录。
  2. 允许 iCloud Drive，并确保网络可用。
  3. 打开 App 设置页查看状态和待同步数量。
  4. 点击“立即同步”；仍失败时重启设备后再试。

导入与导出

设置页可导出普通 JSON 进度文件。导入会替换当前进度并创建新的 iCloud 同步世代，请先保存现有导出文件。

清除数据

设置页的“清除本机及 iCloud 进度”会归零学习状态，但保留本地词库。其他设备下次同步后也会采用新进度。
